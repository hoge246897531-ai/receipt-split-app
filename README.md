# 生活費精算アプリ

レシートを撮影 → 自動でOCR読み取り → 支払者(A/B)ごとに記録 → 月ごとに生活費の折半差額と家賃精算額を自動計算する、ブラウザで動くアプリ（PWA）です。

## 特徴
- カメラでレシートを撮影 → [Tesseract.js](https://tesseract.projectnaive.io/) が端末内でOCR処理（外部送信なし）
- 金額・日付は自動抽出＋手動修正可能
- データはすべて端末のブラウザ内（IndexedDB）に保存。サーバーには一切送信されません
- iPhoneのSafariで「ホーム画面に追加」すればアプリのように起動可能（オフライン対応）
- Mac・Xcode・Apple Developer Program は一切不要

## 精算ロジック
1. 今月のAさん合計・Bさん合計を集計
2. 差額の半分を「多く払った方が少なく払った方から受け取るべき額」とする（生活費を折半する場合の調整額）
3. 家賃（設定タブで金額・支払者を設定、初期値: Aさんが¥50,000）から、上記の調整額を差し引いた金額が最終的な家賃の支払額になる

例: Aが家賃50,000円を払う担当で、今月AがBより生活費を8,000円多く払っていた場合 →
Bが本来Aに4,000円払うべきなので、家賃は 50,000 − 4,000 = 46,000円 をAがBに払えばOK、という計算です。

## 使い方（開発・動作確認）

### そのまま開く（PC・簡易確認用）
`index.html` をブラウザで直接ダブルクリックして開けば、UIの見た目や集計ロジックは確認できます。
（`file://` では Service Worker の登録は失敗しますが、動作に支障はありません。カメラ機能はPCでは通常のファイル選択になります。）

### iPhoneで実際に使う（要HTTPS配信）
スマホのカメラ機能・PWAインストールを使うには、HTTPS で配信する必要があります（`file://` やプレーンな `http://` では動きません）。無料のホスティングを使うのが簡単です。

#### 方法A: GitHub Pages（無料・恒久的）
1. GitHubアカウントを作成（未取得の場合）
2. 新しいリポジトリを作成し、このフォルダの中身（`index.html`, `style.css`, `app.js`, `manifest.json`, `service-worker.js`, `icon.svg`）をすべてアップロード
3. リポジトリの Settings → Pages で「Deploy from a branch」→ `main` ブランチ・`/ (root)` を選択
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` でアクセス可能に
5. iPhoneのSafariでそのURLを開き、共有ボタン →「ホーム画面に追加」

#### 方法B: Netlify Drop（最速・アカウント不要でお試し可能）
1. PCのブラウザで https://app.netlify.com/drop を開く
2. このフォルダをそのままドラッグ＆ドロップ
3. 発行されたHTTPSのURLをiPhoneのSafariで開く
4. 恒久的に使うにはNetlifyアカウントでの登録を推奨（無料枠で十分）
